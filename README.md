# AshuSeva

### Public Hospital OPD Queue & Patient Assistance Platform

AshuSeva is a web-based hospital OPD assistance platform designed to help patients register for OPD services, receive a department-wise token, monitor their queue status, estimate waiting time, and plan their recommended arrival time.

The platform also provides a hospital administration dashboard for monitoring department-wise queues and managing patient consultations.

---

## Features

### Patient Features

- Patient registration
- Department selection
- Automatic OPD token generation
- Live queue status
- Current token being served
- Number of patients ahead
- Estimated waiting time
- Estimated consultation turn time
- Recommended arrival time
- Automatic queue refresh
- Token status lookup
- Patient name and age display
- Mobile-friendly interface

### Hospital Administration Features

- Admin dashboard
- Total patients registered today
- Total waiting patients
- Currently serving patients
- Department-wise queue monitoring
- Call next patient
- Complete current consultation
- Consultation start timestamp
- Consultation completion timestamp
